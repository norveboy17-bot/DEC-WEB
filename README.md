# Del English Club Website (Multi-page)

## Run locally
1. Extract the ZIP file.
2. Open the `DEC-WEB` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Use the top navigation to move between pages.

## Pages
- `index.html` — homepage and links to key sections
- `about.html` — about the club
- `activities.html` — TOEFL Prep, Study Night, Public Speaking, Debate, and Writing
- `schedule.html` — semester dates beginning Friday, 16 October 2026; includes search and category filter
- `docs.html` — member guide, guidelines, FAQ, and what to bring
- `join.html` — Instagram QR code; click/tap the QR to enlarge it

## Assets
- `assets/css/base.css` contains the shared theme, typography, navigation, buttons, cards, tables, and responsive styles.
- Each page has a separate CSS file in `assets/css/`.
- `assets/js/main.js` contains shared navigation and utility behavior.
- Page-specific scripts (`activities.js`, `schedule.js`, `docs.js`, `join.js`) are separated in `assets/js/`.
- `assets/images/instagram-qr.png` is the QR image used on the Join page.

The date/time and location notes are left as a proposed plan where your original project did not specify final details. Confirm the QR scans correctly before publishing.
